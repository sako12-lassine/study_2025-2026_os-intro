# Лабораторная работа № 2. Git

## 1. Цель работы

Изучить основные возможности системы контроля версий Git, настройку пользователя и работу с удалённым репозиторием.

## 2. Формулировка задания

Выполнить настройку Git, ознакомиться с SSH-аутентификацией и подписанием коммитов, а также освоить основные операции работы с репозиторием в соответствии с заданием лабораторной работы № 2.

## 3. Ход работы

### 3.1. Настройка Git

Для настройки имени и адреса электронной почты используются команды:

```bash
git config --global user.name "Имя Фамилия"
git config --global user.email "email@example.com"
git config --list
3.2. Работа с SSH
SSH позволяет выполнять аутентификацию при взаимодействии с удалённым репозиторием. Параметры подключения и результат проверки необходимо подтвердить соответствующими скриншотами.
3.3. Подписание коммитов
Git поддерживает подписание коммитов с помощью GPG. Настройка ключа и проверка подписи выполняются командами, предусмотренными заданием лабораторной работы.
3.4. Работа с удалённым репозиторием
Для отправки локальных изменений в удалённый репозиторий используется команда:
git push


Фактический результат выполнения команд подтверждается скриншотами.
4. Результаты выполнения
В этом разделе необходимо разместить реальные скриншоты настройки Git, проверки SSH, настройки и проверки подписи коммитов, а также отправки изменений в удалённый репозиторий.
Если соответствующие скриншоты отсутствуют, результат не считается документально подтверждённым.
5. Заключение
В ходе лабораторной работы рассматриваются настройка Git, аутентификация через SSH, подписание коммитов и взаимодействие с удалённым репозиторием. Итоговый вывод необходимо согласовать с фактически выполненными действиями.
