Лабораторная работа № 3. Markdown

Цель работы

Научиться оформлять отчёты с помощью легковесного языка разметки Markdown.

Основные элементы Markdown

  • Заголовки
  • Полужирный текст и курсив
  • Цитаты
  • Маркированные и нумерованные списки
  • Ссылки
  • Блоки кода
  • Верхние и нижние индексы
  • Математические формулы

Обработка документов

Для преобразования Markdown в PDF и DOCX используется Pandoc.

Пример преобразования:

```bash pandoc report/lab03.md -o report/lab03.docx pandoc report/lab03.md -o report/lab03.pdf ```

Автоматизация

Makefile автоматизирует преобразование Markdown-документов в PDF и DOCX.

Результаты

Созданы версии отчёта в форматах Markdown, PDF и DOCX. Скриншоты лабораторной работы № 2 включены в отчёт.

Заключение

Освоены базовые элементы Markdown и преобразование документов с помощью Pandoc.
