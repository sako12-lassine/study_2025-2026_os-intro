# Слайд 9. Информация о системе

Основные команды диагностики:

```bash
uname -a
cat /etc/os-release
```

- `uname -a` — информация о ядре и архитектуре.
- `cat /etc/os-release` — сведения о дистрибутиве.

# Слайд 10. Ядро, процессор и память

```bash
sudo dmesg
sudo dmesg | grep -Ei 'Linux version|CPU0|MHz|Memory|hypervisor'
free -h
lscpu
```

Команды позволяют изучить сообщения ядра, сведения о процессоре и объём оперативной памяти.

# Слайд 11. Файловые системы

```bash
findmnt
lsblk -f
df -hT
```

- `findmnt` — точки монтирования.
- `lsblk -f` — диски, разделы и типы файловых систем.
- `df -hT` — использование места на файловых системах.
