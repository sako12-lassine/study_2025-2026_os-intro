## 8. Исследование характеристик системы

Для проверки системы Linux применяются команды, позволяющие получить сведения о ядре, дистрибутиве, процессоре, оперативной памяти и файловых системах.

### 8.1. Информация о системе

```bash
uname -a
cat /etc/os-release
Команда uname -a выводит сведения о ядре и архитектуре. Команда cat /etc/os-release показывает информацию об установленном дистрибутиве.
8.2. Информация о ядре и процессоре
sudo dmesg
sudo dmesg | grep -Ei 'Linux version|CPU0|MHz|Memory|hypervisor'


Команда dmesg выводит сообщения ядра. Фильтрация помогает найти сведения о версии Linux, процессоре, частоте, памяти и виртуализации.
8.3. Оперативная память и процессор
free -h


Команда free -h отображает общий, использованный, свободный и доступный объём оперативной памяти.
8.4. Файловые системы
findmnt
lsblk -f
df -hT


findmnt показывает точки монтирования. lsblk -f отображает диски, разделы и типы файловых систем. df -hT показывает использование места на смонтированных файловых системах.
9. Ответы на контрольные вопросы
1. Какая информация содержится в учётной записи пользователя?
Учётная запись содержит имя пользователя, числовой идентификатор UID, идентификатор основной группы GID, дополнительные группы, домашний каталог и используемую командную оболочку. Пароль не хранится в открытом виде в обычной записи пользователя.
2. Приведите примеры команд для работы в терминале.
- man команда — просмотр руководства.
- команда --help — краткая справка.
- pwd — вывод текущего каталога.
- cd каталог — переход в каталог.
- ls -la — просмотр файлов, включая скрытые.
- du -sh каталог — определение размера каталога.
- mkdir имя — создание каталога.
- touch файл — создание пустого файла.
- cp источник назначение — копирование файла.
- mv источник назначение — перемещение или переименование.
- rm файл — удаление файла.
- rmdir каталог — удаление пустого каталога.
- chmod — изменение прав доступа.
- history — просмотр истории команд.
3. Что такое файловая система? Приведите примеры.
Файловая система — способ организации хранения, именования и поиска файлов на носителе информации.
- ext4 — распространённая журналируемая файловая система Linux.
- Btrfs — файловая система Linux с поддержкой подтомов и снимков.
- XFS — журналируемая файловая система, используемая в том числе для больших объёмов данных.
- VFAT/FAT32 — файловая система, используемая, в частности, на EFI-разделах и съёмных носителях.
4. Как посмотреть смонтированные файловые системы?
Для просмотра смонтированных файловых систем применяются команды:
findmnt
df -hT
lsblk -f


5. Как завершить зависший процесс?
Сначала нужно определить PID процесса с помощью ps, top или pgrep. Для обычного завершения используется:
kill PID


Если процесс не завершается, в крайнем случае можно применить:
kill -KILL PID


Принудительное завершение следует использовать осторожно.
