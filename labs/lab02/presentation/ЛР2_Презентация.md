# Цель работы

Изучить систему контроля версий Git и освоить её первоначальную настройку.

Основные задачи:

- настройка параметров Git;
- создание SSH- и GPG-ключей;
- настройка подписи коммитов;
- взаимодействие с GitHub;
- проверка результатов работы.

# 1. Настройка Git

Настроены имя пользователя, электронная почта и параметры обработки окончаний строк.

# 2. SSH-аутентификация
